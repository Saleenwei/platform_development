📖 使用说明 & API 配置指南

    


      
一、CloseAI 聚合 API 配置

      
    
        
  • API Base URL：固定为 https://api.openai-proxy.org/v1/chat/completions，如使用自定义代理请填写对应地址。
    • 
        
  • API Key：在 api.openai-proxy.org 注册后获取，格式为 sk-xxxxxxxx。
    • 
        
  • 模型名称：填写代理平台支持的任意模型 ID，例如 gpt-4o、o3-pro、claude-3-5-sonnet-20241022、gemini-1.5-pro、deepseek-chat 等。
    • 
      


      
二、请求格式（ChatCompletion 标准）

      
本工具发出的请求体格式为标准 OpenAI ChatCompletion 格式：

      
POST https://api.openai-proxy.org/v1/chat/completions
Authorization: Bearer <your-api-key>
Content-Type: application/json

{
  "model": "gpt-3.5-turbo",
  "messages": [
    { "role": "user", "content": "<生成的 Prompt>" }
  ]
}


      
三、等效 cURL 示例

      
curl https://api.openai-proxy.org/v1/chat/completions \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-3.5-turbo",
    "messages": [{"role": "user", "content": "你好"}]
  }'


      
四、合规自动检测规则

      
    
        
  • ✅ 字符长度：包含空格必须 ≤ 30 字符
    • 
        
  • ✅ 促销/诱导词检测：禁止出现 Best、Top、New、Free、Sale、NoAds、Hot、Fire、Download、Update
    • 
        
  • ✅ 博彩高风险词检测：禁止出现 Win Money、Cash、Bet（作为独立词）
    • 
        
  • ✅ 格式检测：禁止全大写、禁止 Emoji、禁止连续标点（!! ?? *** 等）
    • 
        
  • ⚠️ 人工查重：需在 Google Play 手动搜索确认无完全重名
    • 
        
  • ⚠️ 商标检索：需在 WIPO Global Brand Database 检索特有名词
    • 
      


      
五、注意事项

      
    
        
  • API Key 仅保存在浏览器本地，不会上传至任何服务器。
    • 
        
  • AI 生成结果可能存在幻觉（如字符数计算有误），请结合自动检测结果人工复核。
    • 
        
  • 本工具仅进行初步合规筛查，Google Play 查重和 WIPO 商标检索需人工完成。
